# Android SMS Gateway for AI Business Operations Agent

This Android application acts as a dedicated **Cellular SMS Gateway** for your FastAPI backend. It polls pending SMS messages generated by the AI Business Agent and automatically dispatches them to customers using your physical Android phone and its active SIM card.

---

## Key Features

1. **Native SIM Transmission**: Uses Android's native `SmsManager` to dispatch SMS messages directly through your carrier SIM card without third-party paid SMS APIs.
2. **Tamil Unicode Preservation**: Full support for Tamil characters (`உங்கள் கட்டணம் நிலுவையில் உள்ளது.`) and mixed English + Tamil bilingual messages in a single unified message.
3. **Multipart SMS Support**: Long messages are automatically split into standard multipart SMS segments using `SmsManager.divideMessage()`.
4. **Dual-SIM Support**: Automatically detects available SIM cards (SIM 1 / SIM 2) and allows selecting which SIM carrier to dispatch from.
5. **Continuous Background Operation**: Runs a persistent Foreground Service with a status notification and WorkManager periodic backup to prevent Android from killing the background worker.
6. **Double-Send Protection**: Atomically claims messages (`PENDING` → `PROCESSING`) before handing them to the SIM subsystem to avoid duplicate transmissions.
7. **Carrier Delivery Reports**: Listens for cellular radio dispatch confirmations and carrier delivery receipts (`SENT` and `DELIVERED`).

---

## Architecture Flow

```
+-----------------------------+
| AI Business Agent (FastAPI) |
|  - Gemini AI Message Draft  |
|  - SMS Queue (PENDING)      |
+--------------+--------------+
               |
      Internet / HTTPS (Polling with X-Gateway-Key)
               |
               v
+-----------------------------+
|    Android SMS Gateway      |
|  - Foreground Service       |
|  - Atomic Claim             |
|  - SmsManager Multi-SIM     |
+--------------+--------------+
               |
         Local Cellular Radio
               |
               v
+-----------------------------+
|    Customer Mobile Phone    |
|   Receives Unicode SMS      |
+-----------------------------+
```

## Step-by-Step Setup in Android Studio

### 1. Open the Project
1. Launch **Android Studio** (Hedgehog, Iguana, Jellyfish, or newer).
2. Select **File → Open...**
3. Navigate to and select the folder:
   `AI_Business_Agent/android-sms-gateway`
4. Wait for Gradle sync to complete.

### 2. Connect Your Android Device
1. Enable **Developer Options** on your physical Android phone:
   - Go to **Settings → About Phone**.
   - Tap **Build Number** 7 times until you see *"You are now a developer!"*.
2. Enable **USB Debugging**:
   - Go to **Settings → Developer Options → USB Debugging** and turn it ON.
3. Connect your Android phone to your computer via USB cable.
4. When prompted on your phone screen, tap **"Allow USB Debugging"**.

### 3. Build & Install the App
1. In Android Studio, select your physical phone from the device target dropdown in the top toolbar.
2. Click the green **Run (▶)** button (or press `Shift + F10`).
3. The APK will build and install directly onto your device.

*(Alternatively, to build an APK file to install manually: Select **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Transfer the generated `.apk` file to your phone and install it).*

## App Configuration & Usage

1. **Launch the App**: Open **AI SMS Gateway** on your phone.
2. **Grant Permissions**:
   - When prompted, allow **Send and view SMS messages** (`SEND_SMS`).
   - Allow **Make and manage phone calls** (`READ_PHONE_STATE` for dual-SIM detection).
   - Allow **Notifications** (`POST_NOTIFICATIONS` for background service).
3. **Configure FastAPI Backend**:
   - Tap the **Settings (gear)** icon in the top right.
   - **Backend URL**:
     - If testing on local WiFi: `http://<your-computer-ip>:8000`
     - If deployed on Render: `https://ai-business-agent-ui7z.onrender.com`
   - **SMS Gateway API Key**: Enter your configured key (e.g. `sms_gateway_secret_key_2026`).
   - **Polling Interval**: Default `15` seconds.
   - Tap **Save Settings**.
4. **Select SIM Card**:
   - If your phone has two SIM cards, choose SIM 1 or SIM 2 from the dropdown.
5. **Start Gateway**:
   - Tap **Start Gateway**. The status will turn green (**Active & Listening**).
   - The app is now actively monitoring your business SMS queue.

## Verification & Testing

1. In your Web Application, navigate to **Message Center**.
2. Select a customer with a valid phone number (e.g. `+919876543210`).
3. Click **AI Generate** to draft a message in English, Tamil, or English + Tamil.
4. Click **Send Message**.
   - The web app will show: *"SMS queued successfully. Waiting for Android gateway."*
5. Check your phone:
   - The Android Gateway will fetch the pending message.
   - It claims the message (`PROCESSING`).
   - It transmits the message through your SIM card.
   - It reports back to the server as `SENT`.
6. Refresh the Message Center history or Dispatched Logs:
   - Status updates in real-time to **SENT** with timestamp and device reference.
